# 物流订单分析与可视化项目

## 一、项目简介

本项目基于模拟物流订单数据，使用 WPS Office / Excel
完成物流订单数据统计、数据查询、数据透视分析及可视化。

项目主要用于练习物流业务场景下的数据分析能力。

## 二、使用工具

- WPS Office / Excel
- 数据透视表
- Excel 函数
- 数据可视化

## 三、主要使用函数

- SUM
- AVERAGE
- COUNTIF
- SUMIF / SUMIFS
- XLOOKUP
- SUMPRODUCT
- SUBTOTAL

## 四、项目内容

### 1. 订单数据统计

对物流订单数量、订单金额等指标进行统计分析。

### 2. 基础资料查询

使用 XLOOKUP 将商品、客户、仓库、物流公司等基础资料
与订单数据进行关联。

### 3. 多条件数据分析

使用 SUMPRODUCT 对不同仓库、商品类别等条件进行组合分析。

### 4. 数据透视分析

通过数据透视表分析：

- 不同仓库订单量
- 不同物流公司订单量
- 不同商品类别销售额
- 月度订单趋势

### 5. 数据可视化

制作物流订单分析看板，对分析结果进行可视化展示。

## 五、项目成果

完成物流订单数据统计、分析和可视化，
形成较完整的物流订单数据分析流程。
